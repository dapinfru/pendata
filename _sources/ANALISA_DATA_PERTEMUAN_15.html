PERTEMUAN 15 | Analisa Data#

1. Analisa Prediksi Tentang Apa?#

Analisa Prediksi

Pada studi kasus pada dokumentasi Skforecast, model digunakan untuk memprediksi kebutuhan listrik harian (Demand) di wilayah Victoria, Australia.

Tujuan utama dari analisis ini adalah memperkirakan jumlah kebutuhan listrik pada hari berikutnya berdasarkan data historis kebutuhan listrik sebelumnya dan informasi suhu udara.

Variabel yang tersedia pada dataset antara lain:

  • Demand : kebutuhan listrik.

  • Temperature : suhu udara.

  • Holiday : penanda hari libur.

  • Date/Time : waktu pencatatan data.

Target yang diprediksi oleh model adalah nilai Demand pada periode selanjutnya.

2. Bagaimana Bentuk Data Trainingnya?#

Pada kasus Explainability Skforecast, data time series diubah menjadi bentuk supervised learning menggunakan teknik lag.

Input (X)#

Data input yang digunakan model terdiri dari:

  • lag_1 : Demand 1 hari sebelumnya

  • lag_2 : Demand 2 hari sebelumnya

  • lag_3 : Demand 3 hari sebelumnya

  • lag_4 : Demand 4 hari sebelumnya

  • lag_5 : Demand 5 hari sebelumnya

  • lag_6 : Demand 6 hari sebelumnya

  • lag_7 : Demand 7 hari sebelumnya

  • Temperature : suhu udara

Output (y)#

Output yang diprediksi adalah:

  • Demand (kebutuhan listrik)

Bentuk Data Training#

Tabel berikut merupakan hasil transformasi data time series menjadi data training yang digunakan oleh model forecasting.

import pandas as pd

# Contoh bentuk data training pada kasus forecasting
X_train = pd.DataFrame({
    'lag_1': [170, 180, 190, 200, 210],
    'lag_2': [160, 170, 180, 190, 200],
    'lag_3': [150, 160, 170, 180, 190],
    'lag_4': [140, 150, 160, 170, 180],
    'lag_5': [130, 140, 150, 160, 170],
    'lag_6': [120, 130, 140, 150, 160],
    'lag_7': [110, 120, 130, 140, 150],
    'Temperature': [28.1, 29.3, 27.8, 30.2, 28.9]
})

y_train = pd.DataFrame({
    'Demand': [180, 190, 200, 210, 220]
})

3. Apa Itu Lag?#

Pengertian Lag#

Lag adalah nilai data pada periode sebelumnya yang digunakan sebagai informasi untuk memprediksi nilai pada periode berikutnya.

Dalam forecasting, data masa lalu dianggap memiliki hubungan dengan data masa depan sehingga digunakan sebagai fitur atau variabel input.

Contoh#

Hari

Demand

Senin

100

Selasa

120

Rabu

130

Kamis

?

Jika ingin memprediksi Demand pada hari Kamis maka:

  • lag_1 = 130 (Rabu)

  • lag_2 = 120 (Selasa)

  • lag_3 = 100 (Senin)

Artinya:

  • lag_1 = nilai 1 periode sebelumnya.

  • lag_2 = nilai 2 periode sebelumnya.

  • lag_3 = nilai 3 periode sebelumnya.

Pada kasus Skforecast digunakan 7 lag sehingga model melihat data Demand selama 7 hari terakhir untuk memprediksi hari berikutnya.

4. Jelaskan Proses Analisis yang Dilakukan#

Tahapan Analisis#

1. Mengambil Dataset#

Dataset kebutuhan listrik Victoria digunakan sebagai sumber data untuk proses forecasting.

Variabel yang tersedia:

  • Demand

  • Temperature

  • Holiday

  • Date

2. Persiapan Data#

Data dibersihkan dan diubah menjadi format time series sehingga dapat digunakan oleh model forecasting.

3. Membentuk Variabel Lag#

Data Demand sebelumnya diubah menjadi beberapa fitur:

  • lag_1

  • lag_2

  • lag_3

  • lag_4

  • lag_5

  • lag_6

  • lag_7

4. Membagi Dataset#

Dataset dibagi menjadi:

  • Data Training

  • Data Testing

Data training digunakan untuk melatih model sedangkan data testing digunakan untuk mengukur performa model.

5. Melatih Model#

Model yang digunakan adalah:

  • ForecasterRecursive

  • LGBMRegressor (LightGBM)

Model mempelajari hubungan antara Demand masa lalu dan Temperature terhadap Demand masa depan.

6. Melakukan Prediksi#

Model digunakan untuk memprediksi kebutuhan listrik pada periode berikutnya.

7. Analisis Explainability#

Setelah model menghasilkan prediksi, dilakukan analisis explainability menggunakan:

Feature Importance#

Mengetahui fitur yang paling berpengaruh terhadap prediksi.

SHAP Values#

Menjelaskan kontribusi masing-masing fitur terhadap hasil prediksi.

Partial Dependence Plot#

Menunjukkan bagaimana perubahan suatu fitur memengaruhi hasil prediksi.

8. Interpretasi Hasil#

Berdasarkan hasil analisis, fitur yang paling berpengaruh terhadap prediksi kebutuhan listrik adalah:

  • Temperature

  • Lag Demand sebelumnya

Hal ini menunjukkan bahwa kebutuhan listrik sangat dipengaruhi oleh pola historis dan kondisi suhu udara.
