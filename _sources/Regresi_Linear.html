Regresi Linier#

1. Pengertian Regresi Linier#

Regresi linier merupakan salah satu metode dalam machine learning dan statistika yang digunakan untuk mengetahui hubungan antara variabel bebas (independent variable) dengan variabel terikat (dependent variable). Metode ini digunakan untuk melakukan prediksi nilai berdasarkan pola hubungan data yang dimiliki.

Regresi linier bekerja dengan membentuk sebuah garis lurus terbaik yang mewakili hubungan antara data X dan data Y. Garis tersebut nantinya digunakan untuk memprediksi nilai baru berdasarkan pola yang terbentuk dari data sebelumnya.

Dalam proyek ini digunakan metode regresi linier untuk menganalisis hubungan antara variabel X dan variabel Y menggunakan bahasa pemrograman Python dengan bantuan library sklearn. Selain itu dilakukan juga perhitungan manual menggunakan metode matriks untuk memahami konsep matematis dari regresi linier.

2. Konsep Dasar Regresi Linier#

Regresi linier sederhana memiliki bentuk persamaan sebagai berikut:

\[ y = a + bx \]

Keterangan:

  • ( y ) = variabel terikat

  • ( x ) = variabel bebas

  • ( a ) = intercept atau konstanta

  • ( b ) = slope atau koefisien regresi

Nilai slope menunjukkan besar perubahan nilai ( y ) setiap terjadi kenaikan satu satuan pada nilai ( x ).

3. Rumus Regresi Linier#

Pada proyek ini digunakan metode perhitungan matriks untuk mencari nilai koefisien regresi.

Rumus regresi linier dalam bentuk matriks adalah:

\[ \hat{\beta} = (X^TX)^{-1}X^TY \]

Keterangan:

  • ( X ) = matriks variabel bebas

  • ( X^T ) = transpose matriks X

  • ( (X^TX)^{-1} ) = invers matriks

  • ( Y ) = matriks target

  • ( \hat{\beta} ) = hasil koefisien regresi

Hasil dari perhitungan matriks tersebut akan menghasilkan:

\[\begin{split} \hat{\beta} = \begin{bmatrix} a \\ b \end{bmatrix} \end{split}\]

dimana:

  • ( a ) = intercept

  • ( b ) = slope regresi

7. Membuat Garis Regresi Menggunakan FitLine#

Untuk membuat garis regresi di GeoGebra, digunakan perintah:

FitLine({A, B, C, D, E, F, G})

Dengan data titik milik saya:

A = (2, 2)
B = (4, 3)
C = (3, 5)
D = (3, 4)
E = (3, 3)
F = (4, 5)
G = (5, 6)

Perintah tersebut akan menghasilkan garis regresi berdasarkan seluruh titik data.

Berdasarkan hasil regresi diperoleh persamaan:

y = 0.4 + 1.05x

8. Menghitung Regresi Linier Menggunakan sklearn#

Perhitungan regresi linier juga dilakukan menggunakan Python dengan library sklearn.


import numpy as np
from sklearn.linear_model import LinearRegression

# Data
X = np.array([[2], [4], [3], [3], [3], [4], [5]])
Y = np.array([2, 3, 5, 4, 3, 5, 6])

# Model regresi linier
fitline = LinearRegression()

# Training model
fitline.fit(X, Y)

# Hasil koefisien
beta_0 = fitline.intercept_
beta_1 = fitline.coef_[0]

print("Hasil Regresi Linear dengan sklearn")
print("Beta 0 / Intercept:", beta_0)
print("Beta 1 / Slope:", beta_1)
print(f"Persamaan regresi: y = {beta_0:.6f} + {beta_1:.6f}x")

9. Menghitung Koefisien Regresi Secara Analitik#

Perhitungan analitik dilakukan menggunakan rumus:

β̂ = (XᵀX)⁻¹XᵀY

Karena model regresi yang digunakan adalah:

y = β0 + β1x

maka matriks X dibuat dengan kolom pertama berisi angka 1 sebagai intercept.

X =
[[1, 2],
 [1, 4],
 [1, 3],
 [1, 3],
 [1, 3],
 [1, 4],
 [1, 5]]

Y =
[[2],
 [3],
 [5],
 [4],
 [3],
 [5],
 [6]]

Kode Python untuk perhitungan analitik:

import numpy as np

# Data
x = np.array([2, 4, 3, 3, 3, 4, 5])
y = np.array([2, 3, 5, 4, 3, 5, 6])

# Membentuk matriks X dengan kolom pertama berisi 1
X = np.column_stack((np.ones(len(x)), x))
Y = y.reshape(-1, 1)

# Rumus beta = (X^T X)^-1 X^T Y
XT = X.T
XTX = XT @ X
XTY = XT @ Y
beta = np.linalg.inv(XTX) @ XTY

print("Matriks X:")
print(X)

print("\nMatriks Y:")
print(Y)

print("\nX^T X:")
print(XTX)

print("\nX^T Y:")
print(XTY)

print("\nBeta:")
print(beta)

print("\nBeta 0 / Intercept:", beta[0][0])
print("Beta 1 / Slope:", beta[1][0])
print(f"Persamaan regresi: y = {beta[0][0]:.6f} + {beta[1][0]:.6f}x")

11. Hasil dan Pembahasan#

Berdasarkan data titik A sampai G, diperoleh garis regresi linier dengan persamaan:

y = 0.4 + 1.05x

Nilai β0 atau intercept adalah 0.4, sedangkan nilai β1 atau slope adalah 1.05. Artinya, setiap kenaikan nilai x sebesar 1 satuan akan meningkatkan nilai prediksi y sekitar 1.05.

Hasil dari GeoGebra menunjukkan garis regresi yang mengikuti pola persebaran titik data. Hasil ini sama dengan perhitungan menggunakan sklearn dan rumus analitik matriks. Dengan demikian, proses perhitungan sudah sesuai.

12. Kesimpulan#

Regresi Linier berhasil digunakan untuk menganalisis hubungan antara variabel x dan y pada data titik koordinat. Berdasarkan hasil perhitungan, diperoleh persamaan regresi:

y = 0.4 + 1.05x

Hasil perhitungan menggunakan GeoGebra, Python sklearn, dan rumus analitik memberikan hasil yang sama. Oleh karena itu, dapat disimpulkan bahwa model regresi linier yang dihasilkan sudah benar dan sesuai dengan data yang diberikan.
