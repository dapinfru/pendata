Pertemuan 12 | Analisa Data Menggunakan Random Forest di KNIME#

Identitas Tugas#

Mata Kuliah: Penambangan Data

Topik: Analisa Data Menggunakan Random Forest

Tools: KNIME Analytics Platform

Dataset: Iris Dataset

1. Pengertian Random Forest#

Random Forest adalah algoritma machine learning yang digunakan untuk klasifikasi maupun prediksi. Algoritma ini bekerja dengan cara menggabungkan banyak Decision Tree untuk menghasilkan prediksi yang lebih akurat dan stabil.

Random Forest termasuk metode ensemble learning karena menggabungkan beberapa model untuk meningkatkan performa.

Kelebihan Random Forest#

  • Memiliki akurasi yang tinggi

  • Mengurangi overfitting

  • Dapat menangani data dalam jumlah besar

  • Cocok untuk proses klasifikasi

  • Stabil terhadap noise pada data

2. Dataset yang Digunakan#

Dataset yang digunakan adalah Iris Dataset.

Dataset Iris merupakan dataset klasifikasi bunga berdasarkan ukuran:

  • Sepal Length

  • Sepal Width

  • Petal Length

  • Petal Width

Target klasifikasi pada dataset ini adalah:

  • Setosa

  • Versicolor

  • Virginica

3. Workflow KNIME#

Workflow pada KNIME yang digunakan pada tugas ini adalah:

CSV Reader
↓
Column Filter
↓
Normalizer
↓
Table Partitioner
↓
Random Forest Learner
↓
Random Forest Predictor
↓
Scorer

4. Penjelasan Setiap Node#

4.1 CSV Reader#

Fungsi#

Node CSV Reader digunakan untuk membaca dataset berformat CSV ke dalam KNIME.

Tujuan#

Agar data dapat diproses pada tahap berikutnya.

Screenshot#

4.2 Column Filter#

Fungsi#

Node Column Filter digunakan untuk memilih kolom yang akan digunakan pada proses klasifikasi.

Tujuan#

Untuk menyaring atribut yang diperlukan agar proses analisis lebih efektif.

Alasan Menggunakan Node Ini#

Karena preprocessing data penting dilakukan sebelum proses machine learning.

Screenshot#

4.3 Normalizer#

Fungsi#

Node Normalizer digunakan untuk menormalkan nilai data agar berada pada rentang tertentu.

Pada tugas ini digunakan metode Min-Max dengan rentang:

  • Minimum = 0

  • Maximum = 1

Tujuan#

Agar skala data menjadi seragam dan lebih mudah diproses oleh model.

Screenshot#

4.4 Table Partitioner#

Fungsi#

Node Table Partitioner digunakan untuk membagi data menjadi data training dan testing.

Pembagian Data#

  • Training = 80%

  • Testing = 20%

Tujuan#

Agar model dapat dilatih menggunakan data training dan diuji menggunakan data testing.

Screenshot#

4.5 Random Forest Learner#

Fungsi#

Node Random Forest Learner digunakan untuk membangun model Random Forest.

Target Column#

Pada tugas ini target column yang digunakan adalah:

species

Tujuan#

Untuk melatih model agar dapat mengenali pola pada dataset.

Screenshot#

4.6 Random Forest Predictor#

Fungsi#

Node Random Forest Predictor digunakan untuk melakukan prediksi pada data testing menggunakan model yang telah dibuat.

Fungsi#
